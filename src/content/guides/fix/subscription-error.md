## 订阅更新报错常见类型与解决对策

### 报错一：`Invalid URL / URL format error`
- **成因**：复制订阅链接时，末尾不小心多复制了一个空格，或者缺少了前面的 `https://` 协议头。
- **解决**：清空输入框，回到机场后台重新点击“复制订阅链接”，直接整段粘贴。

---

### 报错二：`Network Error / Connection Refused / Timed out`
- **成因**：机场的订阅分发服务器域名被国内运营商临时阻断，客户端无法直连拉取配置。
- **解决**：
  1. 登录机场官网，查看是否有公告发布了新的**备用订阅转换地址**。
  2. 如果手机端有可用网络，可以在手机上拉取配置后导出为文本文件发送给电脑手动导入。

---

### 报错三：`Empty Profile / Yaml Parse Error`
- **成因**：下载到的内容不是合法的 YAML 配置文件，而是包含 HTML 报错信息的网页（比如 Cloudflare 5秒盾验证页面）。
- **解决**：在浏览器中直接打开你的订阅链接，看看是否能下载到一个文本文件。如果浏览器弹出了 Cloudflare 验证，说明服务商开启了防刷盾，需联系服务商客服或在客户端设置中更新请求头 (User-Agent)。
