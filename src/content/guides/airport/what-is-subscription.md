## 订阅链接是如何工作的？

在过去，如果你要添加 50 个节点，必须手动复制 50 次服务器 IP 和密码。

现在，整个过程被简化为一次链接请求：

```text
机场用户中心 ──复制专属订阅 URL──> 客户端软件（如 Clash Verge）
                                      │
                                      ▼ 发起 HTTPS 请求下载
                               获取最新 YAML / Base64 配置文件
                                      │
                                      ▼ 自动解析
                               生成 50+ 个可视化节点列表
```

---

## 常见订阅格式类型

不同客户端支持的配置格式可能有所差异，主流机场通常提供以下几种格式转换：

1. **Clash 格式 (YAML)**：专供 Clash、Clash Verge、Clash Meta 使用，包含完整的分流规则集、策略组（PROXIES、AUTO、FALLBACK）与节点列表。
2. **Shadowrocket 格式 / 通用 URL 格式**：经过 Base64 编码的纯文本链接，适合小火箭、v2rayN、v2rayNG 直接解析。
3. **Sing-box 格式 (JSON)**：专供新一代 Sing-box 核心使用。

## 订阅链接的安全防护常识

> 警告：你的专属订阅链接相当于你账户的**通信密钥**。

- **切勿公开**：不要将订阅链接公开发布在论坛、微信群、社交媒体或 GitHub 仓库中。
- **防止盗刷**：一旦被扫描爬虫抓取，他人可以随意消耗你的套餐流量，甚至导致你的账户被服务商判定违规共享而封禁。
- **重置订阅**：如果不小心泄露了订阅链接，应立即登录机场用户后台，点击“重置订阅链接 / 重置 UUID”，旧链接将立即作废。
